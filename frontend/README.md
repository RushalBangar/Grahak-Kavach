# Grahak Kavach - Frontend

This directory is reserved for the frontend application of the Grahak Kavach project (Smart India Hackathon).

## Setup Instructions
You can initialize your frontend framework (React, Vue, Next.js, or vanilla HTML/JS) in this folder. 

Once your frontend is running, it should make API calls to the FastAPI backend. You can view the backend API documentation and contract by running the backend server and navigating to `http://localhost:8000/docs`.

### Example (Initializing a Vite React App):
If you want to use Vite and React, you can run the following commands from the root directory (`Grahak-Kavach`):

```bash
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm run dev
```
